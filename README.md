# CallForge — AI Voice Agent Platform

> An AI-powered voice agent platform for creating intelligent customer-facing agents, simulating conversations, qualifying leads, and analyzing call performance.

## Overview

**CallForge** is a web-based AI voice agent platform designed to help businesses create and manage AI-powered customer conversation agents.

The platform allows a business user to define an agent's purpose, configure its language, voice, and communication tone, simulate customer conversations, analyze call outcomes, identify customer intent, score potential leads, and monitor agent performance through a centralized dashboard.

The current version is a **working MVP/prototype** focused on agent creation, simulated calls, AI-powered conversation analysis, lead qualification, and analytics.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/CallForge.git
cd CallForge
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env` file in the project root.

Use `.env.example` as a reference.

```env
GEMINI_API_KEY=your_api_key_here
PORT=3000
NODE_ENV=development
```

**Never commit your `.env` file or API keys to GitHub.**

### 4. Start the backend

```bash
npx tsx server.ts
```

The backend runs on:

```text
http://localhost:3000
```

### 5. Start the frontend

In another terminal:

```bash
npm run dev
```

The frontend runs on:

```text
http://localhost:5173
```

## AI Reliability

The current MVP uses Google Gemini for AI-powered functionality.

AI providers can occasionally experience temporary rate limits, high demand, or service interruptions. A future provider abstraction layer is planned so CallForge can automatically handle provider failures and use an alternative AI provider when necessary.

This will allow the application to continue functioning even when a single AI provider is temporarily unavailable.
